# Documented and run like a team project

**Decision.**
- `README.md` covers getting started, the scripts and where things live.
- `AGENTS.md` holds the rules for people and agents, and `CLAUDE.md` imports it.
- `CONTRIBUTING.md` sets out the workflow.
- `ACCESSIBILITY.md` lists the checks.
- `docs/decisions/` records decisions about content, design and code.

All prose is edited to remove stock AI phrasing.

**Why.** With the setup, rules and decisions written down, a new contributor or agent can pick up the work without a handover, and every choice has its reason on record.
