# Static share image, meta description and SVG favicon

**Decision.** A static 1200×627 Open Graph image with my name and the one-line summary, a title and meta description taken from the same line, and an SVG favicon. Check the preview with LinkedIn's Post Inspector after deploy.

**Why.** Most visits start from a shared link, so the preview is often the first thing someone sees.
