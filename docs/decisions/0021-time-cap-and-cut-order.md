# Two 100-minute sessions, then it goes live as it is

**Decision.** The build has two 100-minute sessions. Whatever state it's in at the end goes live. If time runs short, cut in this order: red and green block placement, then the 5-second test, then the README badge. The quality checks and the commit guard are never cut.

**Why.** A working page that's live is more useful than a better one that isn't. A fixed time with a variable scope, as in Shape Up, forces the choice about what matters.
