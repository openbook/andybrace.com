# Page order puts the reader's problem first and About near the end

**Decision.**
1. Name, one-line summary and a "Get in touch" link
2. Your situation
3. What I bring
4. Proof, as three anonymous client stories
5. How I work with AI
6. About me
7. Where I do my best work, then contact

No writing section until there are posts.

**Why.** Readers see their own problem before the offer. The main action sits at the top, so a reader who's already convinced doesn't have to scroll. An empty writing section would make the page look unfinished. The copy comes from a value proposition written and signed off before the build.
