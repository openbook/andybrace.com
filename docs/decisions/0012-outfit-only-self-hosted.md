# Outfit for all text, self-hosted

**Decision.** One variable font, Outfit, for headings and body text. It's served from this site through `@fontsource-variable/outfit`, not from Google Fonts.

**Why.** Chosen over Jost and two sans-and-serif pairings on a comparison page set with the real copy. One font keeps it to one or two small files. Self-hosting means readers' IP addresses aren't sent to Google.
